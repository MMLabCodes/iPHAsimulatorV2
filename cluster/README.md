# iPHAsimulatorV2 Cluster Installation & GUI GuideThis guide describes the complete workflow for installing and running **iPHAsimulatorV2** on the Swansea University Sunbird cluster.After following this guide you will be able to:- clone the repository- install the simulation environment- install the Streamlit GUI environment- launch the GUI through an SSH tunnel- generate OpenMM simulations- submit simulations directly to Slurm from the GUI---# 1. Clone the repositoryClone the repository into your scratch directory.```bashcd /scratch/$USERgit clone https://github.com/MMLabCodes/iPHAsimulatorV2.gitcd iPHAsimulatorV2```---# 2. Create a working directoryCreate a location for all environments and Conda package caches.```bashmkdir -p /scratch/$USER/iphasimulatorexport IPHA_STORAGE=/scratch/$USER/iphasimulatormkdir -p $IPHA_STORAGE/envsmkdir -p $IPHA_STORAGE/conda-pkgs```You may wish to place these variables in your `.bashrc`.---# 3. Load Mamba```bashmodule load mamba/4.14.0-0```---# 4. Install the simulation environmentCreate the main scientific environment.```bashmamba env create \    --prefix $IPHA_STORAGE/envs/iphasimulator \    -f environment.yml```Activate it```bashsource activate $IPHA_STORAGE/envs/iphasimulator```Verify the installation```bashpython -c "import openmm; print(openmm.__version__)"python -c "import parmed; print(parmed.__version__)"python -c "import rdkit; print(rdkit.__version__)"```---# 5. Install the GUI environmentDeactivate the scientific environment.```bashsource deactivate```Create the GUI environment.```bashmamba env create \    --prefix $IPHA_STORAGE/envs/pha_gui \    -f environment-gui.yml```Activate it```bashsource activate $IPHA_STORAGE/envs/pha_gui```Verify the GUI packages```bashpython -c "import streamlit; print(streamlit.__version__)"python -c "import rdkit"python -c "import parmed"python -c "import py3Dmol"```---# 6. Tell the GUI where the simulation environment livesThe GUI launches simulations using the scientific environment.Set```bashexport IPHASIMULATOR_PYTHON=$IPHA_STORAGE/envs/iphasimulator/bin/python```Confirm```bashecho $IPHASIMULATOR_PYTHON```---# 7. Launch the GUIActivate the GUI environment```bashsource activate $IPHA_STORAGE/envs/pha_gui```Launch Streamlit```bashstreamlit run pha_gui.py \    --server.port 8501 \    --server.address 0.0.0.0```---# 8. Create the SSH tunnelOn your **local computer**, open a new terminal.Run```bashssh -N \    -L 8501:localhost:8501 \    username@sunbird.swansea.ac.uk```Replace `username` with your Swansea username.---# 9. Open the GUIOpen your browser```http://localhost:8501```The iPHAsimulator GUI should now appear.---# 10. Running simulationsThe typical workflow is1. Build polymer2. Build molecular system3. Solvate or create melt4. Register the MD system5. Open the **OpenMM Workflow Builder**6. Select the registered system7. Add simulation steps8. Generate the OpenMM script9. Submit directly to SlurmNo command line interaction is required once the GUI is running.---# 11. Monitoring jobsCurrent jobs```bashsqueue -u $USER```Cancel a job```bashscancel JOBID```---# 12. Monitoring outputGenerated simulation scripts are written to```md_simulation_scripts/```Slurm output is also written there.Watch stdout```bashtail -f slurm_<jobname>_<jobid>.out```Watch stderr```bashtail -f slurm_<jobname>_<jobid>.err```---# 13. Updating the repositoryPull the latest changes```bashgit pull origin main```or, if using the development branch,```bashgit pull origin dan```---# 14. Updating environmentsAfter pulling new changesSimulation environment```bashsource activate $IPHA_STORAGE/envs/iphasimulatormamba env update \    --prefix $IPHA_STORAGE/envs/iphasimulator \    -f environment.yml```GUI environment```bashsource activate $IPHA_STORAGE/envs/pha_guimamba env update \    --prefix $IPHA_STORAGE/envs/pha_gui \    -f environment-gui.yml```---# 15. Directory structure```iPHAsimulatorV2│├── cluster/│   ├── README.md│   ├── submit_openmm_job.sh│   └── ...│├── structure_database/├── md_simulation_scripts/├── src/├── gui/├── environment.yml└── environment-gui.yml```---# NotesThe GUI uses two separate Conda environments.| Environment | Purpose ||-------------|----------|| **iphasimulator** | Scientific simulation environment (OpenMM, AmberTools, RDKit, ParmEd, etc.) || **pha_gui** | Streamlit graphical interface |The GUI automatically launches generated simulations using the **iphasimulator** environment and submits them to Slurm via `cluster/submit_openmm_job.sh`.No manual activation of the simulation environment is required when submitting simulations from the GUI.---Happy simulating! 🚀
